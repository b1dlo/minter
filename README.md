# 🔍 Minter Wallet Seed Phrase Checker

## 📌 Description
This project is designed to check Seed Phrases of Minter Wallets and display:
- Token Balance
- Staking Balance

⚠ **Important:** Use this tool **only** to check **your own wallets**! Never enter someone else's Seed Phrases, as this may lead to a loss of funds.

## 🚀 Usage
1. Create a file named `seeds.txt` inside the `base` folder and add your Seed Phrases (one per line).
2. Run the checker with the following command:
   node main.js
   
3. All results will be saved in the `balance` folder.

## 🔗 About Minter
https://www.minter.network/ is a blockchain platform that allows users to issue, transfer, and exchange tokens with low fees and high transaction speeds. The Minter ecosystem includes staking opportunities, decentralized finance (DeFi), and integration with other blockchains.
